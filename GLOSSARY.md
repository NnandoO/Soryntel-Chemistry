# Glosario del proyecto

Vocabulario de presentación y documentación en español. Las fórmulas, unidades SI, identificadores de funciones y claves de archivos conservan su sintaxis técnica.

| Término técnico | Presentación en español | Uso |
|---|---|---|
| Species | Especie química | Fórmula, fase, carga y registro termodinámico |
| Stream | Corriente | Conjunto de especies y sus cantidades/condiciones |
| Flowsheet | Diagrama de flujo | Unidades de proceso y corrientes conectadas |
| Workbook / Worksheet | Libro / Hoja | Documento de un módulo / tabla dentro de él |
| Heat and material balance | Balance de materia y energía | Cierre de materia y entalpía por corrientes |
| Heat loss | Pérdidas de calor | Transferencia neta por conducción, convección y radiación |
| Heat capacity | Capacidad calorífica | Cp; especificar base molar o másica |
| Enthalpy / Entropy | Entalpía / Entropía | H / S; indicar unidades y referencia |
| Gibbs energy | Energía de Gibbs | G; identificar propiedades estándar o de mezcla |
| Activity coefficient | Coeficiente de actividad | γ; no confundir con actividad |
| Phase | Fase | Gas, líquido, sólido o fase acuosa |
| Pure substance | Sustancia pura | Distinguir de una fase mezcla |
| Fixed activity | Actividad fija | Condición de contorno con posible intercambio de materia |
| Infinite phase | Fase infinita | Reservorio del modelo de equilibrio |
| Sweep | Barrido | Serie o malla de cálculos sobre variables independientes |
| Target / Goal seek | Objetivo / Búsqueda de objetivo | Ajustar una variable para lograr una condición |
| Convergence | Convergencia | Criterios numéricos declarados; no certifica exactitud del modelo |
| Residual | Residual | Diferencia entre una restricción y el valor calculado |
| Extrapolation | Extrapolación | Evaluación fuera del intervalo de datos; debe comunicarse |
| Estimate | Estimación | Resultado de un modelo aproximado; distinguir de dato tabulado |
| Dead state | Estado ambiental de referencia | Base de la exergía física y química |
| LCA / LCI / LCIA | ACV / Inventario / Evaluación de impactos | Análisis del ciclo de vida y sus etapas |
| Data reconciliation | Reconciliación de datos | Ajuste de mediciones según restricciones e incertidumbres |
| Thermal conductivity | Conductividad térmica | k en W/(m·K) |
| Emissivity | Emisividad | Propiedad adimensional; indicar espectral/total cuando proceda |
| Saturation | Saturación | Coexistencia de fases bajo las condiciones especificadas |

Las capacidades numéricas del código y la disponibilidad de un control en la interfaz no se describirán como rangos científicos validados sin evidencia.

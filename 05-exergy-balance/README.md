# Módulo 05 — Exergy Balance (Documentación REA)

Esta carpeta contiene la especificación técnica, matemática y de auditoría **REA (Reverse Engineering & Architecture)** para el **Módulo 5: Exergy Balance** de **Soryntel Chemistry**, preparada antes de implementar código o interfaz gráfica.

## Documentos incluidos

1. [`REA_ANALYSIS.md`](REA_ANALYSIS.md) — Auditoría de fuentes en `HSC6` (`33 Data References.txt`, `Maindb6.HSC`) y capacidades ya existentes en `soryntel-thermo`.
2. [`MATHEMATICAL_SPECIFICATION.md`](MATHEMATICAL_SPECIFICATION.md) — Ecuaciones completas de exergía física, exergía química (Szargut 1988), exergía de mezcla, exergía térmica/trabajo, destrucción de exergía e indicadores de eficiencia.
3. [`FUNCTIONAL_SPECIFICATION.md`](FUNCTIONAL_SPECIFICATION.md) — Requerimientos funcionales, modos de cálculo, descomposición por corrientes y áreas de balance.
4. [`UI_SPECIFICATION.md`](UI_SPECIFICATION.md) — Arquitectura preliminar de interfaz (pendiente de ajuste fino con las capturas que enviará el usuario).
5. [`VALIDATION_PLAN.md`](VALIDATION_PLAN.md) — Plan de pruebas numéricas y verificación de Segunda Ley ($I = T_0 S_{\text{gen}} \ge 0$).
6. [`SCIENTIFIC_REFERENCES.md`](SCIENTIFIC_REFERENCES.md) — Referencias bibliográficas primarias verificadas.

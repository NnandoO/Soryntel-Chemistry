## Matriz Cuantitativa de Validación (`MB-01 .. MB-10`)

| ID | Área Validada | Caso de Referencia Observado | Criterio de Aceptación Verificable |
|---|---|---|---|
| **MB-01** | Topología y cierre de flujo circuito Rougher | Circuito `Conditioner + Rougher 1..5` (`Figs. 3, 11, 20, 22`): `Feed -> Conditioner -> RC Feed -> Rougher 1..5` | Ecuaciones generadas coinciden exactamente: `Feed = RC Feed` y `RT_{k-1} = RT_k + RC_k`. Conservación por unidad: residuo absoluto $\|\sum e^{\text{unit}} F\|_\infty < 10^{-10}$ (`Fig. 22`: `1.76E-11`) y `Tolerance Error < 10^{-13}` (`Fig. 22`: `1.17E-15`). |
| **MB-02** | Ecuación lineal entre corrientes (`Stream by Equation`) | `Feed Mass = 2 * RC1` (`Fig. 12`) | Al activar restricción lineal $F_i = c\, F_j$, el solver EWTLS satisface $\|F_i^{\text{bal}} - c\, F_j^{\text{bal}}\| < 10^{-12}$ y clasifica `Bal. Status = Calculated` aun cuando el valor medido de $F_i$ sea `Missing`. |
| **MB-03** | Modelos de Error (`Tabla 3`) y Calidad (`Tabla 4`) | Ley mineral `Cu` con `Fixed Relative a=5`, `S-shape (a=5, b=0.01, c=0.5)`, `Mineral Grade (a=5)`, `Whiten PSD` y `Sample Quality` (`Good=1, Moderate=1.5, Bad=3`) | - `Fixed Absolute`: `SD = a`, `Sampling Error = 0`.<br>- `Fixed Relative`: `SD = (a/100)*x`, `Sampling Error = 0`.<br>- `Whiten PSD`: para `x = 5%`, `SD = 0.6`; para `x = 15%`, `SD = 1.0`.<br>- `Mineral Grade`: `x = 4%` $\implies$ `RSD% = 2.5%`.<br>- `S-shape + Sampling Error`: escala efectiva incluye factor `1.0 / 1.5 / 3.0`. |
| **MB-04** | Fórmula de Escalamiento (`Figs. 17–18`) | Matriz numérica `Assays` y `AssaysSD` (`Fig. 18`, 8 corrientes, `indexOfInput = 2`) | Verificación directa contra `Assays_scaled = Assays ./ (100 * repmat(AssaysSD(2,:), 8, 1))`: p.ej. fila `1`, col `1`: $1.3360 / (100 \times 0.3684) = 0.036265 \approx 0.0363$; fila `7`, col `1`: $41.0950 / (100 \times 0.3684) = 1.115499 \approx 1.1155$. Discrepancia $< 10^{-4}$ respecto a valores de `Fig. 18`. |
| **MB-05** | Reconciliación Unsized EWTLS + WLS y Estadísticas | Circuito flotación `Rougher` (`Figs. 15–16, 20–23`, `Mass + 4 elementos` o `4 minerales`): `RT5=13899`, `RC1=464`, `RC2=118.4`, `RC3=166.7`, `RC4=207.6`, `RC5=241.1` | Convergencia EWTLS dentro de `Balance Tolerance = 0.001` en $\le 10$ rondas (`Fig. 15`: `4` rondas). Cierre exacto `Feed = Sum(RC1..5) + RT5` ($\approx 15097\text{ g}$). Consistencia con `WSSQ` (`Eq. 1`): suma exacta de $(a_{ij} - b_{ij})^2 / s_{ij}^2$ sobre celdas activas; recuperación total `Feed = 100.0%`, suma de recuperaciones `RC1..5 + RT5 = 100.0%` $\pm 10^{-8}$. |
| **MB-06** | Solvers con Restricciones (`LS`, `LS MinMax`, `NNLS`, `CLS`, `LLS`) y `Sum = 100` | Datos sintéticos con componente negativo en `LS` o cotas `[Min, Max]` (`51.7.1`) | - `NNLS`: todas las incógnitas $b_m \ge 0$.<br>- `CLS`: $\text{lb}_m \le b_m \le \text{ub}_m$ en el `100%` de variables acotadas.<br>- `LLS`: $F > \text{SD}_F$ y $W > \text{SD}_W$ en modo `Unsized`.<br>- `Assay Sum = 100` / `Mineral Sum = 100`: $|\sum_e G_{\text{flow},e} - 100| < 10^{-9}$ eliminando 1 fila de $B$ para conservar rango completo (`Eq. 11`). |
| **MB-07** | Balance Unsized con Agua y `% Sólidos` (`Solids, water and assays`) | Corriente de pulpa con `F`, `W` y `PcM` (`Eqs. 5–7`) | Coherencia física exacta posbalance: $\left|Pc_{\text{bal}} - \frac{100\,F_{\text{bal}}}{F_{\text{bal}} + W_{\text{bal}}}\right| < 10^{-8}$ y $\sum e^{\text{unit}} W_{\text{bal}} = 0$. |
| **MB-08** | Balance `Sized` (sin ensayos por malla) + Unidad `Size Transforming` | Circuito molienda + hidrociclón (`Fig. 25`: `SAG` marcado `Size Transforming = true`; `Cyclone` `false`) (`Eqs. 12–18`) | - Balance global de masa $F_{\text{tot}}$ se cumple en **`SAG` y `Cyclone`** (`Eq. 12`).<br>- Ecuaciones granulométricas por malla (`Eqs. 13, 17`) se exigen únicamente sobre `Cyclone` (excluido `SAG`) y cumplen $\sum_{i} M_{\text{flow},i} = 100$ (`Eq. 18`). |
| **MB-09** | Balance `Sized by Assay` (`Eqs. 19–29`) y Bloque Diagonal | Prerrequisito `Unsized/Sized` resuelto (`F_{tot}` y `G_{tot}` fijados), luego subflujos y leyes por malla | - Subflujos por malla suman exacto al total: $|\sum_s F_{\text{flow},s} - F_{\text{flow,tot}}| < 10^{-9}$ (`Eq. 20`).<br>- Consistencia de ley cabeza (`Eq. 28`): $\left|\sum_s F_{\text{flow},s} G_{\text{flow},e,s} - F_{\text{flow,tot}} G_{\text{flow,tot},e}\right| < 10^{-8}$.<br>- Seleccionar `Method = LLS` dispara aviso/bloqueo Regla `#12` (`51.6`). |

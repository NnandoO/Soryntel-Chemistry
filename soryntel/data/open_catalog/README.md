# Catálogo abierto de Soryntel

Este directorio solo admite registros con licencia redistribuible documentada.
No contiene archivos de HSC Chemistry ni datos extraídos masivamente de NIST.

`species.csv` contiene intervalos termodinámicos; `provenance.csv` contiene
licencia, URL, versión y hash de cada fuente. El validador exige unidades SI,
rango de temperatura válido y licencia resuelta antes de distribuir datos.

Copias de las especificaciones locales excluidas por el .gitignore de la raíz, recuperadas el 17 de noviembre de 2026. El manifiesto registra origen y SHA-256. Las imágenes y binarios no se copian; los enlaces relativos a imágenes requieren los originales locales.
